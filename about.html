🌙 About AstroAI

AstroAI is an astrology-based web application created as a college project.

🔮 What is AstroAI?

AstroAI is a simple and interactive website that helps users explore zodiac signs, basic astrology, horoscopes and astrology-related information.

🤖 AI Chatbot

AstroAI includes an AI-powered chatbot that allows users to ask questions about zodiac signs, astrology concepts and general horoscope-style guidance.

💻 Technologies Used

HTML, CSS and JavaScript are used for the frontend. Node.js and Express are used for the backend, while an AI API powers the chatbot.

✨ Our Goal

Our goal is to create a simple, user-friendly and interactive astrology website while demonstrating modern web development and AI integration.
